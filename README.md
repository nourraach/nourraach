### 🏥 Health & Fitness

#### 💪 [FitLife](https://github.com/nourraach/fitness-app-backend) — Nutrition & Fitness Tracker `PFE 2025`

The biggest thing I've shipped. A health platform for users who want to track meals, log workouts, talk to a coach, and compete with friends — all in one backend.

| Feature | How |
|---|---|
| 📸 Food recognition | Photo → Clarifai AI → nutritional breakdown, instantly |
| 💬 Coach messaging | WebSocket channels, real-time, persistent history |
| 🏆 Friend challenges | Create a goal, invite friends, live leaderboard |
| 📊 Progress charts | Calories, macros, weight, activity — over time |
| 🔔 Notifications | Per-user preferences, push + in-app |
| 🔐 Auth | JWT · role-based (user / coach / admin) |

`Spring Boot 3.2` `Java 17` `Angular` `PostgreSQL` `WebSocket` `Clarifai API` `JWT`

### 🛒 E-Commerce

#### 🛍️ [ShopSphere](https://github.com/nourraach/Projet_SOA_backend) — Online Store with SOA Backend `Projet SOA`

A properly layered e-commerce platform. Services are decoupled, orders have a lifecycle, and the whole thing runs in Docker.

| Feature | How |
|---|---|
| 🔐 Authentication | JWT login + Google OAuth2 — user's choice |
| 🛒 Cart & checkout | Quantities, promo codes, stock checks |
| 📦 Order lifecycle | Admin approves → ships → delivers, with email at each step |
| ❤️ Wishlist | Save items, filter by category and price |
| 🐳 Deployment | Docker Compose — full stack in one command |

`Spring Boot` `Angular 18` `PostgreSQL` `Google OAuth2` `JavaMailSender` `Docker`

[![Backend](https://img.shields.io/badge/Backend-CE9EA8?style=flat-square&logo=github&logoColor=white)](https://github.com/nourraach/Projet_SOA_backend)
[![Frontend](https://img.shields.io/badge/Frontend-b07d8e?style=flat-square&logo=github&logoColor=white)](https://github.com/nourraach/Projet_SOA_frontend)

Built during my internship to replace a paper-and-spreadsheet workflow. Zero framework — pure PHP MVC designed and implemented from scratch.

- Two roles with completely separate dashboards: **Admin** and **User**

`PHP` `MySQL` `Custom MVC` `Bootstrap`

### 🏠 Real Estate

#### 🔑 [LocaSpace](https://github.com/nourraach/projet-d-integration-back) — Property Rental Platform `Projet Intégration`

Multi-semester integration project: a Symfony REST API consumed by an Angular 18 frontend, managing listings with photos, pricing, and surface data.

- Serialization groups keep API responses lean and intentional
- Doctrine ORM with migration history — schema changes are tracked
- Docker Compose for a reproducible dev environment across the team

`Symfony 7` `Angular 18` `PostgreSQL` `Doctrine ORM` `Docker`
